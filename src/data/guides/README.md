# Guide content

These 19 articles were adapted from [GOV.PH Guides — researched drafts](https://app.notion.com/p/3f4e4ba4b72f81c2b564f120a8f9d46b) on 13 October 2026. The source collection states that its research was reviewed on **9 October 2026**. This is the source review date, not a claim that the adaptation reverified every external source.

`manifest.json` stores the index summaries, stable route IDs, source page URLs, review dates, procedure-step counts and estimated reading times. Each matching `.md` file contains public-facing guidance and references. Notion callouts and tables were converted to Markdown blockquotes and GFM tables. Existing `/guides?topic=...` links redirect to the corresponding article.

Internal fact-check tables, claim verdicts and source-retrieval notes belong in the original Notion drafts, not in the public articles. Unsupported specifics are omitted or replaced with practical directions to the responsible agency. Do not remove an uncertainty label while leaving its unsupported claim presented as fact. Keep source links for retained claims and update reference numbers when removing sources.

The `umid` route is retained, but the public title describes the MySSS Card replacement covered by the draft. The guide index summaries were rewritten to reflect the researched content instead of the placeholder claims.

Update the article and its manifest entry together. `steps` counts numbered procedure steps across all application routes (excluding the reference list). Reading time is estimated at 200 words per minute, excluding reference URLs and the reference list. Do not advance `reviewedAt` just because code or wording changed. Preserve meaningful conditions, exceptions and source links for public guidance.

These are repository-owned snapshots. There is no runtime Notion request and no change to the existing CMS sync. Article rendering and content load only when a guide route is opened.
